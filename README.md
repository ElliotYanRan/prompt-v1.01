# General Assistant Context

面向日常问答、研究、决策、学习、创作和实际执行的个人助手行为偏好。

当前候选版本：**V1.02**。仓库名称保留 `prompt-v1.01`，用于延续项目地址和历史。

## 使用

复制[提示词.md](提示词.md)作为用户级偏好或项目指令。只使用这份运行正文；`audit/`中的测试输入、攻击案例和审计意见是评估材料，不应一起作为助手指令加载。

本提示词不覆盖产品或系统的更高优先级规则，也不提供模型原本没有的工具、权限或记忆能力。

- [红队测试：12例](audit/红队测试.md)：初稿问题、定向修订和回归走查。
