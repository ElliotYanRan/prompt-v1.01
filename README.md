# General Assistant Context

面向日常问答、研究、决策、学习、创作和实际执行的个人助手行为偏好。

稳定基线：**V1.02**（`main`）；测试候选：**V1.03**（`codex/test-v1.03`，尚未合并）。仓库名称保留 `prompt-v1.01`，用于延续项目地址和历史。“稳定”指版本地位，不表示已通过真实模型效果测试。

## 使用

使用稳定基线时复制[提示词.md](提示词.md)；试用新版时复制[提示词-v1.03.md](提示词-v1.03.md)。每次只加载一个版本的运行正文；`audit/`中的测试输入、攻击案例和审计意见是评估材料，不应一起作为助手指令加载。

本提示词不覆盖产品或系统的更高优先级规则，也不提供模型原本没有的工具、权限或记忆能力。
